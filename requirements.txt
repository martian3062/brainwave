# --- The spine -------------------------------------------------------------

anthropic==0.120.0

# --- Postgres on Render (SQLite is the local fallback, no driver needed) ----
# The marker is not decoration. psycopg2-binary 2.9.10 publishes wheels up to
# cp313 only; on a 3.14 interpreter pip falls back to building from source,
# needs pg_config, and `pip install -r requirements.txt` dies -- taking every
# other package in the file down with it, because pip resolves before it
# installs. Render runs the pinned python-3.11.9 (runtime.txt), gets the cp311
# manylinux wheel, and is unaffected. Local dev falls back to SQLite and needs
# no driver at all. Raise the bound when a psycopg2-binary release ships cp314
# wheels.
psycopg2-binary==2.9.10; python_version < "3.14"
